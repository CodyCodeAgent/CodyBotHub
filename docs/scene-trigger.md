# 场景回复触发

在「场景路由 → 创建 / 编辑场景 → 回复触发」配置「仅 @ 当前机器人时回复」。

- 开启：群聊和话题必须明确 @ 当前机器人；仅命中场景规则不会触发任务、收件表情或回复。
- 关闭：保持按场景规则自动处理消息的能力；机器人来源限制、允许列表和防循环规则仍然生效。
- 私聊不受此开关限制，仍遵循原有路由规则。
- 新建场景默认开启。历史场景迁移后保留自动处理行为，避免影响告警场景；需要按场景手动开启。
- 未匹配场景的群聊和话题默认要求 @ 当前机器人。

此配置属于 CodyBotHub 的场景触发策略，无需修改 CodyWebCore。任务统计卡片开关独立配置，仍只对用户明确 @ 当前机器人的消息发送统计通知。
